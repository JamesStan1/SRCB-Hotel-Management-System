# Leave Management System - Quick Reference Guide

## For Staff Members

### How to Request Leave

1. **Navigate to Leave Request:**
   - Dashboard → Staff Management → Request Leave

2. **Fill the Form:**
   - **Leave Type:** Select from dropdown (Vacation, Sick Leave, etc.)
   - **Start Date:** Click to pick first day of leave
   - **End Date:** Click to pick last day of leave
   - **Reason:** (Optional) Explain why you need leave

3. **Review Information:**
   - System shows number of days requested
   - Displays if approval is needed
   - Shows if leave is paid or unpaid

4. **Submit:**
   - Click "Submit Request"
   - You'll see a success message
   - Request status becomes "Pending"

### How to Check Leave Status

1. **View Your Leave History:**
   - Dashboard → Staff Management → Leave History

2. **Check Status:**
   - **Pending** (Yellow) - Waiting for manager approval
   - **Approved** (Green) - Request accepted, leave is confirmed
   - **Rejected** (Red) - Request declined, see rejection reason

3. **View Details:**
   - Click "View" on any request to see full details
   - See approval date and approving manager name
   - Check rejection reasons if applicable

### Statistics You Can See

- **Total Requests:** All your leave requests ever made
- **Approved:** Requests that were accepted
- **Pending:** Waiting for approval
- **Days Used:** Total approved leave days taken

### Leave Types Available

| Leave Type | Days/Year | Requires Approval? | Paid? |
|---|---|---|---|
| Vacation | 20 | Yes | Yes |
| Sick Leave | 10 | No | Yes |
| Unpaid Leave | — | Yes | No |
| Personal Leave | 3 | Yes | Yes |
| Maternity Leave | 180 | Yes | Yes |
| Paternity Leave | 10 | Yes | Yes |
| Bereavement Leave | 5 | Yes | Yes |

### Tips

✓ **Request early** - Give managers time to find coverage
✓ **Be specific** - Provide reasons for better approval chances
✓ **Check balance** - Don't exceed your annual allocation
✓ **Add reason** - Helps managers make faster decisions

## For Managers & HR Staff

### How to Review Leave Requests

1. **Access Approvals Dashboard:**
   - Dashboard → Staff Management → Leave Approvals

2. **Review Pending Requests:**
   - See all pending requests with staff name and dates
   - Statistics show total pending for overview
   - Filter by status to organize requests

3. **Review Details:**
   - Click "Review" on a request
   - See staff member, dates, leave type, and reason
   - Check number of days requested

### How to Approve a Request

1. **Open Request Details:**
   - Click "Review" on pending request in the modal

2. **Check Information:**
   - Verify dates and staffing impact
   - Review the stated reason
   - Confirm leave type and duration

3. **Approve:**
   - Click "Approve" button
   - Request status changes to "Approved"
   - Staff member is notified (in future versions)

### How to Reject a Request

1. **Open Request Details:**
   - Click "Review" on pending request

2. **Enter Rejection Reason:**
   - Fill "Rejection Reason" field with explanation
   - Be specific about why it's rejected
   - (e.g., "Insufficient staffing during this period")

3. **Reject:**
   - Click "Reject" button
   - Request status changes to "Rejected"
   - Reason is saved for staff reference

### Dashboard Overview

**Three Key Statistics:**
- **Total Requests:** All leave requests from all staff
- **Pending Review:** How many need your approval
- **Processed:** Approved + Rejected count

### Filtering Options

- **All:** View all requests (pending + approved + rejected)
- **Pending:** Only requests waiting for approval (Focus here!)
- **Approved:** Already approved requests
- **Rejected:** Previously rejected requests

### Best Practices

✓ **Review regularly** - Don't let pending requests pile up
✓ **Communicate** - If rejecting, be specific about reasons
✓ **Plan ahead** - Discuss with team about coverage
✓ **Document** - System automatically tracks all approvals
✓ **Be consistent** - Apply same policies to all staff

### Tips for Managers

1. **Prevent Coverage Issues:**
   - Ensure key people aren't all out same week
   - Review leave requests early
   - Plan cross-training ahead of time

2. **Efficient Processing:**
   - Check pending requests daily
   - Make decisions quickly to avoid delays
   - Use filters to organize requests

3. **Staff Relations:**
   - Explain rejection reasons clearly
   - Try to approve reasonable requests
   - Recognize patterns (personal days, seasons)

## Common Scenarios

### Scenario 1: Staff Requests Vacation During Peak Season
**Action:** Review dates carefully, check coverage, approve/reject based on operations

### Scenario 2: Sick Leave With No Advance Notice
**Status:** Most sick leaves auto-approve (check leave type settings), staff notifies manager

### Scenario 3: Staff Exceeds Annual Leave Allowance
**Prevention:** System should warn (monitor leave_balances), HR can approve unpaid time

### Scenario 4: Urgent Leave Request
**Process:** Staff can request, manager reviews immediately, approval same-day possible

### Scenario 5: Manager Approved Leave That Conflicts
**Solution:** Manager can reject new conflicting requests, or discuss alternatives with staff

## Troubleshooting

### "I can't request leave"
- Check you have active account and are logged in
- Ensure you're accessing from Staff Management menu
- Try refreshing the page

### "My request disappeared"
- Check different status filters
- May have been rejected (check Rejected filter)
- Contact HR if still missing

### "As manager, I can't see leaves to approve"
- Verify you have Manager, HR, or Admin role
- Check access permissions with admin
- Ensure Leave Approvals page loads properly

### "Rejection reason not saving"
- Reason field is required when rejecting
- Make sure you filled in a reason
- Check for any error messages

### "Dates won't sync properly"
- Ensure dates are in correct format
- Start date must be before end date
- Try clearing and re-selecting dates
